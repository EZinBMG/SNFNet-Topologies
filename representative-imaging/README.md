# Representative AFM images

Representative AFM images associated with Figure 1 of *Crystalline Seed Identity Selects Assembly Topology in Silk Fibroin*.

| File | Sample | Figure 1 region |
| --- | --- | --- |
| `APS-SNC.tif` | Top-down silk nanocrystal (SNC) seeds | SNC seed AFM image |
| `HISA-SNF.tif` | Seed-free silk nanofibril (SNF) network | Seed-free AFM overview |
| `RSFSNC.tif` | SNC-mediated core-arm network | Seed-mediated AFM overview |

The images show the AFM Height Sensor channel and include lateral scale bars and height color scales. The file-to-sample mapping is also provided in `image_manifest.csv`. Image files are supplied unchanged.

Related simulation code: [SNFNet-Topologies](https://github.com/EZinBMG/SNFNet-Topologies).
